# WB Toolbox v4 Native Alpha 38

WB Toolbox v4 是原生 WPF 重写版。它不使用 WebView2、HTML、CSS 或 JavaScript，主窗口、悬浮小窗、输入控件和动画全部由 Windows 桌面控件渲染。

## 当前 Alpha 功能

- 人民币、卢布、美元、日元任意换算
- 行情卡同时显示 CNY/RUB、USD/RUB 与 100 JPY/RUB，并可选择、交换主行情币种
- MOEX 即时行情与俄罗斯央行交叉汇率
- “互译”支持中文、俄语、英语、日语；Google、Bing 与 MyMemory 并发竞速并缓存最近 64 条结果，限流后按 Retry-After 暂停重复请求
- 新增 1个、2个、3个、5个数量快捷翻译；常用数量短语使用本地词形规则即时返回，不等待网络
- 翻译页打开时预热 Bing 会话，普通文本以约 1 秒为目标抢先返回；网络较慢时备用请求最多等待 15 秒且可取消。错误提示自动换行，悬停可查看各通道原因；公共服务耗时仍取决于网络与限流情况
- WB DPX 东莞自发货定价
- 平台佣金率与利润率均可编辑、校验并保存
- 定价模块内置 7,435 条 WB 类目佣金；可按商品或品类关键词搜索，选择后自动带入佣金，并保留手动调整能力
- 原生置顶、拖动、缩放、可拖动透明悬浮图标
- 本地设置与缓存
- 新安装默认使用纯白浅色主题，界面采用黑、白与中性灰组合；仍可切换纯黑深色模式
- 黑白配色仅用于纯白、纯黑默认背景；图片与视频背景自动恢复蓝色玻璃轮廓，并为定价方案区域使用更通透的专属层级
- 图片与视频背景采用柔和遮罩和更稳定的内容底色；定价页减少嵌套描边，让输入、结果、明细和说明形成清晰层级
- 使用简洁的英文“WB”品牌图标，并统一显示英文产品名 WB Toolbox
- 默认使用浅色纯白、深色纯黑背景；原天空少女背景已移入“背景皮肤”，并继续支持自定义本地图片与静音循环视频背景
- 选择视频时自动打开区域选择窗口，可重新框选、拖动、缩放并保存显示区域
- 视频循环保留 Alpha 29 的单播放器原位回绕；备用层只冻结已解码的片头画面，在主视频回到 0ms 时短暂遮住媒体表面清空产生的局部黑帧，不参与接力播放
- 汇率、翻译、定价、输入框、普通按钮和弹出面板统一采用更通透的玻璃层级，自定义图片与视频背景保持清晰可见，同时保留文字和边框对比度
- 保留旧版液态玻璃界面、功能菜单和外观面板；三个功能窗口高度更接近，定价页采用紧凑排版
- 自定义背景按中心等比裁切；宽而矮的窗口也能铺满背景，内容区在合理宽度内居中
- 气泡、行情脉冲、弹簧切页和按钮反馈动画
- 主窗口与悬浮图标之间采用 iOS 风格圆角形变、收拢缩放、弹性展开与短时高斯模糊过渡
- 悬浮图标位置会自动保存；缩小精确收拢到图标，恢复时从图标返回上一次主窗口位置
- 300×420 最小窗口自动等比缩放，主操作面不会被裁切
- 大窗口按可用宽高自适应排版，不再整体放大文字；矮宽窗口不会退化为窄条；支持 Per-Monitor V2 DPI 切换
- 拖动调整窗口大小时暂停装饰动画与卡片阴影重绘，并合并连续布局请求
- 页面滚动条默认隐藏，鼠标滚轮、触控板和触摸滚动保持可用
- 顶部操作区使用 Lucide 开源矢量图标，在不同 DPI 下保持清晰
- 单实例启动；再次双击会唤醒已有窗口
- 功能页按需创建，非汇率页不进行后台行情轮询
- 主窗口拖到屏幕左、右、上、下边缘并松手后立即缩回；鼠标进入边缘窄条后立即弹出，拖离边缘即可解除
- 贴边缩回与弹出使用可中途反向的 Q 弹欠阻尼动画，展开端带约 12px 柔和回弹且始终保留圆角；隐藏期间暂停背景装饰动画以降低占用
- 已缩回到屏幕边缘时会从 Alt+Tab 中隐藏但保留任务栏入口；Win+D 后会在不抢焦点的情况下自动恢复边缘窄条，鼠标碰边即可再次 Q 弹展开；普通未贴边窗口仍遵循标准 Win+D 最小化行为（应用内“－”按钮仍进入悬浮图标）
- AnyCPU 发布，可在 Windows 11 x64 与 ARM64 的 .NET Framework 环境运行
- 启动失败时显示中文原因，并将详细日志写入 `%LOCALAPPDATA%\WBToolbox\logs`

## 系统要求

- Windows 11 或 Windows 10 1809 及以上
- .NET Framework 4.8（Windows 11 已内置）
- 推荐使用安装版；便携版需要让 `.exe` 与同名 `.exe.config` 保持在同一文件夹

## 构建

在 PowerShell 中运行：

```powershell
.\Build-Native.ps1
```

输出位于 `dist\WB-Toolbox-v4.0.0-alpha.38.exe`。

执行完整测试并生成便携发布包：

```powershell
.\Build-Release.ps1
```

发布构建默认运行确定性的本地核心测试、真实窗口转场回归和空闲性能预算。需要检查实时行情与公共翻译服务时，显式执行：

```powershell
.\Build-Release.ps1 -RunLiveIntegration
```

在线测试可能因第三方接口限流或网络不可用而失败，不影响本地计算测试的可信度。

生成带开始菜单、可选桌面快捷方式和卸载入口的 Windows 安装程序：

```powershell
.\Build-Installer.ps1
```

安装程序采用按用户安装，不需要管理员权限。构建安装程序需要 Inno Setup 6。
简体中文安装文案来自 MIT 许可的 Inno Setup Chinese Simplified Translation，许可文件保存在 `Installer\Languages\LICENSE`。

当前构建脚本使用 Windows 自带的 .NET Framework 4.8 编译器，方便在没有 SDK 的机器上立即构建。项目已经按 Core、Services、UI 分层，后续安装 .NET 10 SDK 后可直接迁移目标框架。

## 性能原则

- 不创建 WebView2/Chromium 进程。
- 不使用实时背景模糊；透明玻璃由原生渐变绘制。
- 背景使用解码尺寸受控的静态缓存图层，避免空闲时持续重绘；气泡动画只改变缓存图层的位移、缩放和透明度。
- 视频背景在窗口最小化、贴边隐藏、进入悬浮模式或交互缩放时自动暂停，恢复可见后继续静音循环。
- 主窗口隐藏或功能页折叠时暂停持续装饰动画，恢复时从原动画相位继续。
- 卡片和悬浮图标的阴影使用静态独立图层，不随内部动画重复重绘。
- 行情只由一个后台服务每 10 秒刷新；窗口隐藏或离开汇率页时暂停。
- 悬浮状态使用独立原生窗口，不缩放网页快照。
- 页面和控件动画使用 WPF 合成层，不启动 Chromium 子进程。
- 高斯模糊只在窗口与悬浮图标切换期间启用，过渡完成后立即从视觉树移除。
- 转场快照限制像素规模并在进入悬浮状态后释放，避免长期占用大尺寸 GPU 表面。

## 快捷键

- `Ctrl+1`：汇率换算
- `Ctrl+2`：四语翻译
- `Ctrl+3`：WB 定价
- `Ctrl+M`：缩小为原生悬浮窗
